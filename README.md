# Jenkins SonarQube Nexus CI/CD Pipeline

This project is a simple CI/CD pipeline setup using **Jenkins, SonarQube, and Nexus**.

The main purpose of this project is to understand how code can be built, tested, analyzed for code quality, and stored as an artifact using different DevOps tools.

## Tools Used

* Jenkins
* Git / GitHub
* Maven
* SonarQube
* Nexus Repository
* Java

## Pipeline Flow

The basic flow of the project is:

```text
Developer
   |
   v
GitHub
   |
   v
Jenkins
   |
   +----> Maven Build
   |
   +----> Tests
   |
   +----> SonarQube Code Analysis
   |
   +----> Nexus Repository
```

## What this project does

1. The source code is maintained in GitHub.
2. Jenkins pulls the latest code from the repository.
3. Maven is used to build the application.
4. Unit tests are executed as part of the build.
5. SonarQube is used to check the code quality.
6. The generated artifact is uploaded to Nexus Repository.
7. Jenkins manages the complete CI/CD flow.

## Prerequisites

Before running the project, make sure the following are installed and configured:

* Java
* Maven
* Jenkins
* SonarQube
* Nexus Repository
* Git

Jenkins should also have the required credentials and integrations configured for GitHub, SonarQube, and Nexus.

## Jenkins Pipeline

The Jenkins pipeline is defined in the `Jenkinsfile`.

The pipeline is responsible for automating the build and other CI steps instead of running everything manually.

A typical pipeline looks like:

```text
Checkout
   ↓
Build
   ↓
Test
   ↓
SonarQube Analysis
   ↓
Package
   ↓
Upload Artifact to Nexus
```

## SonarQube

SonarQube is used in this project to perform static code analysis.

It helps identify things like:

* Bugs
* Code smells
* Security issues
* Code coverage
* Maintainability problems

## Nexus

Nexus Repository is used to store the application artifact generated by Maven.

For example:

```text
target/
└── application.jar
```

The artifact can then be uploaded to Nexus from the Jenkins pipeline.

## How to Run

Clone the repository:

```bash
git clone https://github.com/richakri/jenkins-sonar-nexus.git
cd jenkins-sonar-nexus
```

Build the project using Maven:

```bash
mvn clean package
```

Then the Jenkins pipeline can be configured using the `Jenkinsfile`.

## Learning Purpose

I created this project to get hands-on experience with Jenkins and understand how different DevOps tools can be connected together in a CI/CD pipeline.

The project can be extended later by adding Docker, Kubernetes, AWS, or other deployment tools.
